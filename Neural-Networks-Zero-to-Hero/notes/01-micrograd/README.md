## 一句话总结

神经网络本质上是一个可调参数组成的数学表达式：前向传播计算预测值和损失，反向传播用链式法则求出每个参数对损失的影响，梯度下降再沿着降低损失的方向更新参数。

## 学习目标

学完本课后，应该能够：

- 解释导数和梯度在神经网络中的意义；
- 将一个标量表达式表示成计算图；
- 用链式法则手算反向传播；
- 理解一个最小自动微分引擎的实现；
- 用 `Neuron → Layer → MLP` 组合神经网络；
- 写出完整的训练循环，并理解常见错误。

## 1. 全局图景

```text
输入 x + 参数 θ
      │
      ▼
  前向传播 forward
      │
      ├──► 预测值 ŷ
      │
      ▼
  损失函数 L(ŷ, y)
      │
      ▼
  反向传播 backward
      │
      ├──► 每个参数的梯度 ∂L/∂θ
      │
      ▼
参数更新 θ ← θ - η∇θL
      │
      └────────── 重复 ──────────┘
```

训练的核心并不神秘：重复计算、求导、更新参数，直到损失足够小。

## 2. 导数：一个变量如何影响另一个变量

对于函数 $y=f(x)$，导数定义为：

$$
f'(x)=\lim_{h\to 0}\frac{f(x+h)-f(x)}{h}
$$

直觉上，导数描述：当 $x$ 发生一个很小的变化时，$y$ 会如何变化。

- $f'(x)>0$：增大 $x$ 会使 $y$ 增大；
- $f'(x)<0$：增大 $x$ 会使 $y$ 减小；
- $|f'(x)|$ 越大：$y$ 对 $x$ 越敏感；
- $f'(x)=0$：在该点附近，改变 $x$ 对 $y$ 的一阶影响很小。

在神经网络中，最终关注的是损失 $L$ 对参数 $w$ 的导数：

$$
\frac{\partial L}{\partial w}
$$

它回答了一个直接的问题：稍微改变 $w$，损失会朝哪个方向、以多快的速度变化？

### 数值求导只用于检查

可以用有限差分近似导数：

```python
def numerical_derivative(f, x, h=1e-6):
    return (f(x + h) - f(x)) / h
```

它直观但速度慢，并受浮点误差和步长影响。训练神经网络时使用反向传播高效地计算解析梯度；数值求导更适合作为梯度检查工具。

## 3. 计算图与 `Value`

把表达式拆成基本运算，就能得到一个有向无环图（DAG）。例如：

$$
L=(a\times b)+c
$$

```text
a ─┐
   ├─ (*) ─ d ─┐
b ─┘           ├─ (+) ─ L
c ─────────────┘
```

micrograd 用 `Value` 包装每一个标量。一个节点需要记录：

| 属性 | 含义 |
|---|---|
| `data` | 前向传播得到的标量值 |
| `grad` | 最终输出对当前节点的导数 |
| `_prev` | 产生当前节点的父节点 |
| `_op` | 产生当前节点的运算 |
| `_backward` | 根据局部导数把梯度传给父节点的函数 |

当执行 `a * b` 或 `a + b` 时，不只是计算数值，还会连接父节点、记录运算，并保存相应的局部反向规则。这样，普通的 Python 表达式就会在运行时动态建立计算图。

## 4. 反向传播 = 局部导数 × 上游梯度

若中间变量 $z=g(x)$，最终输出 $L=f(z)$，链式法则为：

$$
\frac{\partial L}{\partial x}
=
\frac{\partial L}{\partial z}
\frac{\partial z}{\partial x}
$$

每个节点只需要知道两件事：

1. 当前节点收到的上游梯度；
2. 自己这一步运算的局部导数。

常见标量运算的反向规则：

| 前向运算 | 对输入的局部导数 | 反向传播 |
|---|---|---|
| $z=x+y$ | $\partial z/\partial x=1$ | `x.grad += z.grad` |
| $z=x\times y$ | $\partial z/\partial x=y$ | `x.grad += y.data * z.grad` |
| $z=x^n$ | $\partial z/\partial x=nx^{n-1}$ | `x.grad += n*x**(n-1)*z.grad` |
| $z=\tanh(x)$ | $\partial z/\partial x=1-z^2$ | `x.grad += (1-z**2)*z.grad` |

反向传播从最终输出开始，因此先令：

```python
loss.grad = 1.0  # d(loss) / d(loss)
```

然后按照计算图的逆拓扑顺序调用每个节点的 `_backward()`。必须先处理子节点，父节点才能收到完整的上游梯度。

## 5. 最容易忽略的实现细节：梯度必须累加

若同一个变量通过多条路径影响输出，总梯度是每条路径贡献之和：

$$
\frac{\partial L}{\partial x}
=
\sum_i \left.\frac{\partial L}{\partial x}\right|_{\text{path }i}
$$

例如 $y=x+x$，应有 $dy/dx=2$。因此反向函数中必须使用：

```python
x.grad += contribution
```

不能写成 `x.grad = contribution`，否则后处理的路径会覆盖之前的梯度。这也是实现自动微分时最关键的 bug 之一。

## 6. 从一个神经元到 MLP

单个神经元先计算输入的加权和，再经过非线性激活：

$$
n=\sum_i w_i x_i+b,\qquad o=\tanh(n)
$$

各部分含义：

- $x_i$：输入；
- $w_i$：每个输入对应的权重；
- $b$：偏置；
- $\tanh$：非线性激活函数；
- $o$：神经元输出。

如果没有非线性激活，无论堆叠多少线性层，整体仍等价于一个线性变换，无法表达复杂的非线性关系。

micrograd 按下面的层次组合网络：

```text
Value  →  Neuron  →  Layer  →  MLP
标量      多个参数     多个神经元    多层网络
```

- `Neuron(nin)`：接收 `nin` 个输入并输出一个标量；
- `Layer(nin, nout)`：并行放置 `nout` 个神经元；
- `MLP(nin, [n1, n2, ...])`：把多个层顺序连接。

## 7. 损失函数与梯度下降

预测完成后，需要一个标量衡量预测和目标的差异。课程中的小例子使用平方误差：

$$
L=\sum_i(\hat y_i-y_i)^2
$$

随后用梯度下降更新每个参数：

$$
\theta \leftarrow \theta-\eta\frac{\partial L}{\partial\theta}
$$

其中 $\eta$ 是学习率。负号表示朝损失下降的方向移动。

### 完整训练循环

```python
for step in range(num_steps):
    # 1. forward：得到预测和损失
    y_pred = [model(x) for x in xs]
    loss = sum((yp - y) ** 2 for yp, y in zip(y_pred, ys))

    # 2. zero_grad：清除上一次迭代留下的梯度
    for p in model.parameters():
        p.grad = 0.0

    # 3. backward：计算本次损失对所有参数的梯度
    loss.backward()

    # 4. update：沿负梯度方向更新参数
    for p in model.parameters():
        p.data += -learning_rate * p.grad
```

这个顺序非常重要：`forward → zero_grad → backward → update`。

## 8. 与 PyTorch 的关系

micrograd 和 PyTorch 的核心思想相同：运算在前向过程中构建计算图，调用 `backward()` 后自动求梯度。

| micrograd | PyTorch |
|---|---|
| 面向教学，代码很少 | 面向生产与研究，功能完整 |
| 主要操作标量 | 高效操作多维 Tensor |
| Python 实现，容易看懂 | 底层高度优化，可使用 GPU |
| 展示自动微分的本质 | 提供完整深度学习生态 |

micrograd 慢不是因为原理不同，而是它把张量中的每个元素拆成独立标量运算。现代框架使用向量化和并行计算来高效执行相同思想。

## 9. 易错点

### 9.1 梯度覆盖而不是累加

计算图出现分支时必须用 `+=` 累加各路径贡献。

### 9.2 忘记清零梯度

梯度默认会累积。每轮训练在 `backward()` 前应将参数的 `grad` 清零，否则混入历史梯度。

### 9.3 参数更新方向写反

要最小化损失，应使用 `parameter -= learning_rate * gradient`。

### 9.4 反向顺序错误

计算图必须先拓扑排序，再逆序传播。父节点如果过早反向，会漏掉尚未传来的梯度。

### 9.5 原地更新参与计算图的数据

参数更新应在一次完整的前向和反向之后进行。PyTorch 中通常放在 `torch.no_grad()` 环境下，避免把更新操作本身记入计算图。

### 9.6 学习率不合适

学习率太大可能震荡或发散，太小则训练很慢。它控制每次参数更新的步幅，不是越大越好。

## 10. 我现在如何理解反向传播

反向传播不是一种新的微积分规则，而是把链式法则有组织地应用到计算图：

1. 前向传播保存中间结果和运算关系；
2. 从损失节点的梯度 `1` 开始；
3. 每个节点用「上游梯度 × 局部导数」计算对父节点的贡献；
4. 多条路径的贡献相加；
5. 逆拓扑遍历确保依赖顺序正确。

它之所以高效，是因为每个中间节点的梯度只需计算一次并复用，而不是对每个参数分别重新计算整个表达式。

3. 链式法则在计算图中如何工作？
4. 为什么计算图有分支时必须累加梯度？
5. 为什么反向传播前要进行拓扑排序？
6. 非线性激活函数为什么必要？
7. 忘记清零梯度会发生什么？
8. 学习率太大或太小分别会怎样？
9. micrograd 和 PyTorch 的原理有哪些相同点？

<details>
<summary>参考答案</summary>

1. `data` 保存前向值，`grad` 保存最终输出对该节点的导数。
2. 因为 $dL/dL=1$，它是反向传播的起点。
3. 节点把上游梯度乘以本地运算的局部导数，再传给父节点。
4. 同一变量通过多条路径影响输出，总导数等于各路径贡献之和。
5. 子节点要先收齐梯度，之后才能向它的父节点传播完整结果。
6. 多层线性变换仍等价于单层线性变换；非线性让网络可以拟合复杂关系。
7. 新梯度会与旧梯度累加，参数更新不再只对应当前批次或当前迭代。
8. 太大容易越过最低点甚至发散，太小会导致收敛缓慢。
9. 都是动态构建计算图并用反向模式自动微分；主要差别在数据规模、性能与工程能力。
